# ADR-001: 예약 시간 처리

상태: 승인
날짜: 2026-10-07

## 맥락
시간 처리는 AI가 가장 자주 제각각으로 만드는 부분이다. 시간대, 단위, 겹침 기준이 정해지지 않으면 팀원마다 다른 코드가 나온다.

## 결정
- 입력은 `date`(YYYY-MM-DD), `start`·`end`(HH:mm). 모두 **한국 시간(+09:00)** 으로 해석한다.
- 30분 단위만 허용한다. 운영 시간 09:00–22:00, 한 번에 최대 240분.
- 구간은 **시작 포함·종료 미포함** `[start, end)`. 맞닿는 예약은 겹침이 아니다.
- 현재 시각은 `createApp({ now })`로 주입받는다. 도메인 코드에서 `new Date()`를 직접 부르지 않는다.

## 결과
- 테스트에서 시각을 고정할 수 있어 취소 마감 같은 규칙을 정확히 검증한다.
- AI는 시간대 라이브러리를 추가하거나 다른 시간 형식을 제안하지 않는다.
