# S3 관리자 하루 현황 — 스펙 (Ready)

## 스토리

관리자로서, 룸별 하루 예약 현황을 보고 싶다. 그래야 청소와 운영 인력을 배치할 수 있다.

## 인수조건

```gherkin
시나리오: 관리자 조회
  Given 2026-10-20 A룸에 예약 2개, B룸에 1개, 취소된 A룸 예약 1개가 있을 때
  When  관리자가 A룸의 2026-10-20 현황을 조회하면
  Then  200과 함께 A룸의 확정 예약 2개를 시작 시각 순으로 받는다

시나리오: 관리자가 아님
  When  일반 회원이 조회하면
  Then  403 FORBIDDEN

시나리오: 날짜 누락
  When  date 없이 조회하면
  Then  400 VALIDATION_ERROR
```

## 제약 · 금지

- 관리자 판별은 ADR-002의 `X-Role: admin` 헤더로만 한다
- 금지: 비밀번호를 코드나 쿼리 문자열에 넣기
